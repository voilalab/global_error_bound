# Bounding Global and Local Compression Error of Signal Parameterizations
 
This repository contains the code for reproducing the main experiments in the paper **Bounding Global and Local Compression Error of Signal Parameterizations**. It implements the four compressive parameterizations studied in the paper — Grid, Fourier Feature Networks (FFN), Instant-NGP, and GA-Planes — and reproduces the global error curves and local error heatmaps reported in the main text and appendix.

---

## Prerequisites
 
### System
 
- NVIDIA GPU with compute capability ≥ 6.1. All experiments in the paper were conducted on an NVIDIA RTX A6000 (48 GB VRAM); memory usage was not a limiting constraint.
- NVIDIA Driver compatible with your CUDA version
- A working CUDA toolchain compatible with the installed PyTorch and JAX builds.
- Linux or WSL2 environment.
- Conda (Anaconda or Miniconda).

### Frameworks
 
Following Appendix D.2 of the paper:
 
- **PyTorch** — used for all 2D and 3D direct fitting and MRI experiments (Grid, FFN, Instant-NGP, GA-Planes).
- **JAX** — used for the radiance-field (NeRF) experiments.
Standard Python scientific-computing dependencies (NumPy, Matplotlib, Jupyter) are required to run the notebooks and generate figures.
 
### Recommended Version for Compatibility

| Library       | Recommended Version |
|---------------|---------------------|
| Python        | 3.13                |
| PyTorch       | 2.9.x               |
| CUDA Toolkit  | 12.2                |
| Jax           | 0.9.0               |
| gcc / g++     | 9–11 (for tiny-cuda-nn) |

## Running Global Error-Curve Experiments

Global error curves are generated by training models at multiple compression levels or model sizes.

The main capacity parameter swept for each model is:

| Model | Model Name | Swept Parameter |
|------|------|-----------------|
| Grid | `grid` | Grid resolution |
| FFN | `ffn` | MLP width |
| Instant-NGP | `instant-ngp` | Hash-table size |
| GA-Planes | `ga-planes` | Feature dimension |

Run the relevant experiment script from one of the following folders.

### 2D Direct Fitting and 2D MRI

```bash
cd global_error_curves/2d_signals
python <model_name>_eta.py --dataset <dataset>
```

Supported dataset options:

```text
div2k, bandlimited, sphere, mri
```

### 3D Direct Fitting

```bash
cd global_error_curves/3d_signals
python <model_name>_eta.py --dataset <dataset>
```

Supported dataset options:

```text
dragon, bandlimited, sphere
```

### 3D MRI

```bash
cd global_error_curves/3d_mri
python <model_name>_eta.py
```

### 3D NeRF

```bash
cd global_error_curves/3d_nerf
python <model_name>_eta.py
```

After running the experiment scripts, generate the global error-curve figures with:

```bash
jupyter notebook global_error_curves/plot_global_error_curves.ipynb
```

## Running Local Error-Heatmap Experiments

Local error heatmaps are generated by training a small model and a larger model from the same architecture family, then comparing their outputs pointwise.

For a small model `g_small` and a larger model `g_large`, the predicted local error map is:

```text
c * |g_small - g_large|
```

where `c` is the architecture-specific calibration constant.

Run the relevant notebook in:

```text
local_error_heatmaps/
```

Examples:

```bash
jupyter notebook local_error_heatmaps/grid_2d_signals.ipynb
jupyter notebook local_error_heatmaps/ffn_3d_mri.ipynb
jupyter notebook local_error_heatmaps/instant-ngp_3d_nerf.ipynb
jupyter notebook local_error_heatmaps/ga-planes_3d_dragon.ipynb
```

After running the model-specific notebooks, generate the final heatmap figures with:

```bash
jupyter notebook local_error_heatmaps/plot_local_error_heatmaps.ipynb
```

## Notes

- Non-NeRF experiments are implemented in PyTorch.
- NeRF experiments are implemented in JAX.
- Global error curves compare adjacent compression levels or model sizes.
- Local heatmaps compare a small and large model from the same architecture.
- MRI experiments use k-space supervision.
- NeRF experiments use photometric rendering loss.
